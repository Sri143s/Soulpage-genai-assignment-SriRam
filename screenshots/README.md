# 📸 Application Screenshots & Visual Artifacts

This directory contains placeholders for visual UI screenshots demonstrating both task features:

- `task1_company_intelligence.png`: Streamlit UI rendering the multi-agent workflow visualizer, metrics cards, executive summary, risks, opportunities, and sources.
- `task2_conversational_bot.png`: Streamlit chat UI showing turn 1 ("Who is the CEO of OpenAI?") and turn 2 ("Where did he study?") with pronoun context resolution badge and source expanders.
- `fastapi_swagger_docs.png`: Swagger UI documentation generated by FastAPI at `http://localhost:8000/docs`.

To generate fresh screenshots, run the Streamlit app (`python main.py ui`) or FastAPI server (`python main.py server`).
